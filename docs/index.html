Questions, answered.

Something else? Ask in the Telegram group or open an issue.

Do I need root?

Yes. Xposed frameworks like LSPosed need root to run, and the app needs root access as well.

Is it only for Pixel phones?

No. It works with the launcher, not the phone. Any device running Pixel Launcher (com.google.android.apps.nexuslauncher) or Launcher3 (com.android.launcher3) is supported. Launchers with other package names are not.

Which Android versions work?

Android 12 or newer is recommended. The app installs on Android 8.0 and up, but features aren’t guaranteed there. If you try an older version, reports on what works are welcome.

Do changes need a launcher restart?

Many settings apply right away. The rest take effect once the launcher restarts, which the app can do for you.
